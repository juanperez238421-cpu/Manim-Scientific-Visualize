# Statistics 10 — IQR Class 02 storyboard

## Objective
Compare two boxplots on the same numerical scale and justify a conclusion using median, IQR, whiskers and outliers.

## Case data
- Group A: 4, 5, 6, 6, 7, 7, 8, 8, 9, 10, 10, 11
- Group B: 3, 4, 5, 6, 7, 7, 8, 9, 10, 12, 14, 22

Using the median-of-halves convention from Class 01:
- Group A: Q1=6, M=7.5, Q3=9.5, IQR=3.5; fences 0.75 and 14.75; no outliers.
- Group B: Q1=5.5, M=7.5, Q3=11, IQR=5.5; fences -2.75 and 19.25; 22 is a potential outlier.

## Narrative
1. Recap the reading order for a boxplot.
2. Introduce the two ordered datasets.
3. Calculate the five-number summaries and fences.
4. Draw both boxplots on one shared 0–24 number line.
5. Compare center, middle 50%, whisker span and outliers one feature at a time.
6. Explain why an outlier is a flag for investigation, not an automatic deletion.
7. Apply the comparison to a decision case.
8. End with a six-step reproducible comparison method and exit ticket.
