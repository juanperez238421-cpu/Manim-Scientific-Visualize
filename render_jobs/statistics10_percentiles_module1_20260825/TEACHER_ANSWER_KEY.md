# Statistics 10 — Module 1 Teacher Answer Key

## Class convention
Use one convention throughout:

\[r=1+(n-1)\frac{k}{100}\]

If the position is fractional, interpolate linearly between the two adjacent ordered values.

## Worked data used in the presentation
Ordered scores: 52, 60, 63, 68, 72, 75, 80, 84, 90, 96.

- P25: r=3.25 -> 63+0.25(68-63)=64.25.
- P50: r=5.5 -> 72+0.5(75-72)=73.5.
- P75: r=7.75 -> 80+0.75(84-80)=83.
- P80: r=8.2 -> 84+0.2(90-84)=85.2.
- D3=P30: r=3.7 -> 63+0.7(68-63)=66.5.
- D7=P70: r=7.3 -> 80+0.3(84-80)=81.2.

## Student Practice
### Level 1
Q2=P50 -> 50%; D7=P70 -> 70%; P80 -> 80%.

### Level 2
Data: 40,45,50,55,60,65,70,75,80. r=1+8(0.75)=7, so P75=70.
Interpretation: about 75% of observations are at or below 70.

### Level 3
If P30=58: about 30% of observations are at or below 58.

### Level 4
Group A: P75=82.5. Group B: P75=95. Group B has the higher 75th-percentile value; the practical meaning depends on the variable.

### Level 5
If an exam report gives P80=86: about 80% of scores are at or below 86 points, using the stated class convention.
