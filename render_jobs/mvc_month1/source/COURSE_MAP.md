# Mapa curricular y decisiones de diseño

## Enfoque pedagógico

- Comenzar con representaciones geométricas antes de formalizar ecuaciones.
- Conectar cada objeto 2D con su lectura 3D cuando sea relevante.
- Mantener figura y ecuación visibles al mismo tiempo.
- Usar color semántico consistente: azul para objetos base, naranja para dirección/variación, verde para resultado geométrico y rojo para conclusiones o puntos críticos.
- Aplicar cámara 3D solo cuando agrega información, no como efecto decorativo.

## Cobertura

### Semana 1 — Geometría vectorial
- Vectores en R² y R³.
- Componentes cartesianas.
- Magnitud.
- Producto punto.
- Ángulo y proyección.

### Semana 2 — Geometría analítica en R³
- Producto cruz.
- Área del paralelogramo.
- Vector normal.
- Recta paramétrica.
- Plano cartesiano.
- Intersección recta–plano.

### Semana 3 — Funciones de varias variables
- Gráfica z=f(x,y).
- Curvas de nivel.
- Lectura topográfica.
- Límite en dos variables.
- Dependencia del camino.

### Semana 4 — Diferenciación multivariable
- Derivadas parciales.
- Cortes coordenados.
- Gradiente.
- Dirección de máximo crecimiento.
- Plano tangente.
- Aproximación lineal.
